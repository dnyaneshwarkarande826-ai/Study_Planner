# Smart Study Planner

## About the Project
Smart Study Planner is a C++ console-based application designed to help students organize their daily study plans.

## Features
- Student details
- Daily study goal
- Add subjects
- Study hours for each subject
- Marks tracking
- Daily tasks
- Study plan display

## Technologies Used
- C++
- Standard C++ libraries

## How to Run
1. Open the project in VS Code.
2. Compile the program using a C++ compiler.
3. Run the generated program.

## Purpose
The project helps students manage their study time and subjects in an organized way.
